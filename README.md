# Suyosha Animuthyalu 🐨

The official dictionary of everything Suyosha says.

**Live site:** https://koala-keeper.github.io/suyosha-animuthyalu/

Want to add a saying? Open the site and tap **➕ Add a saying**. No account needed, and it shows up for everyone right away. Sayings are stored in a small free Supabase database.
