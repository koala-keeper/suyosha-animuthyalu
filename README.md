# Suyosha Animuthyalu 🐨

The official dictionary of everything Suyosha says.

**Live site:** https://koala-keeper.github.io/suyosha-animuthyalu/

Want to add a saying? Open the site and tap **➕ Add a saying**, or [open a new issue](../../issues/new?labels=saying&title=%F0%9F%90%A8%20) with the saying as the title. It shows up on the site right away.
